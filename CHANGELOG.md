# Changelog

## 1.0.0 — Public Portfolio Release

- **Document Parsing:** Comprehensive support for text extraction from PDF and DOCX files.
- **Compliance Validation:** Robust rule engine to validate document structure, sections, terminology, spelling, and metadata.
- **Vulnerability Intelligence:** Integrated knowledge base matching to detect and categorize over 100 cybersecurity vulnerabilities within documents.
- **Branding Validation:** Computer-vision based logo matching (ORB and pHash) to enforce corporate branding guidelines.
- **Report Generation:** Automated export of compliance findings to PDF, DOCX, and TXT formats.
- **Desktop UI:** Modern, responsive CustomTkinter interface with multiple themes, a scan dashboard, and developer diagnostics.
- **Packaging:** Standalone executable generation for Windows via PyInstaller.
- **Confidentiality Sanitization:** Complete removal of organization-specific references, real reports, and sensitive artifacts for a safe public portfolio release.
